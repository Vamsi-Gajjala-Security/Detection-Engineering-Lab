# Detection-Engineering-Lab

A practical Detection Engineering repository focused on Microsoft Sentinel analytics rules, KQL detections, and MITRE ATT&CK mappings.

Detections are developed in a lab environment using simulated data. A detection is marked Tested only after it has been validated and its tuning documented. No client, employer, or production data is included.
**Detection Rules**
Rule	MITRE ATT&CK	Data Source	Status
Password Spray	T1110.003	SigninLogs	Planned

**Documentation Standard**
Each detection folder contains:
KQL Detection Query
Threat Description
Detection Logic
MITRE ATT&CK Mapping
Threshold Justification
False-Positive Analysis
Tuning Recommendations
Investigation Guidance
Test Notes and Validation Results
**Repository Goals**
Build practical Microsoft Sentinel detection content
Improve KQL and detection engineering skills
Document testing and validation methodologies
Apply MITRE ATT&CK-based detection development
Maintain reusable detection content and tuning notes
**Status**
This repository is currently under active development.

A detection is marked Tested only after successful validation against simulated laboratory data and documented tuning activities.
